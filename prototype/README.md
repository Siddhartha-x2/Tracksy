# Original Tracksy interface prototype

These files preserve the first standalone interface mockup:

- `index.html` — the original page structure.
- `app.css` — the original styles.
- `app.js` — sample interactions and fictional data stored in browser local storage.

This historical mockup has no backend authentication, PostgreSQL persistence, protected evidence storage, or enforceable faculty review. Its role selector is a demonstration control.

The current Tracksy application is implemented in `../frontend/` and `../backend/`, using React + TypeScript, Spring Boot, and PostgreSQL. Follow the [project setup instructions](../README.md) to run it.
